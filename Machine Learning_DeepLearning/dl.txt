38. Forward Pass Cheat Sheet
Definition
Forward pass = moving input through the neural network to produce a prediction.

Single layer
\[
\boxed{Z=XW+b}
\]
Then:
\[
\boxed{A=f(Z)}
\]
Deep network
\[
Z_1=XW_1+b_1
\]
\[
A_1=f(Z_1)
\]
\[
Z_2=A_1W_2+b_2
\]
\[
A_2=f(Z_2)
\]
Continue until output.
Terminology
X → input
W → weights
b → bias
Z → pre-activation
A → activation/output
f → activation function

Classification outputs

0 → 1

Typically:

class probabilities
